# RL course

强化学习课程项目：在 PCPO 的 OCR 任务中使用贝叶斯优化指导训练提示采样。

## BO选点改进

[查看完整交付包](BO选点改进/) · [队友先读](BO选点改进/README_队友先读.md) · [下载交付包 ZIP](BO选点改进.zip)

包内提供 提示特征与 Matérn-5/2 核、GP、UCB/logEI 选点、奖励归组、断点恢复，以及针对现有单 GPU PCPO 驱动的接入代码。

每轮选择 8 条提示，每条生成 8 张图，前 20 轮随机预热，随后按最近 50 轮观测选点。整次训练不重复提示文本，随机对照也使用此规则。v1 优先选择预测平均 OCR reward 较低的提示；新方法“基于BO的改进强化学习训练采点v2”优先选择预测组内 reward 方差较大的提示。PCPO 始终使用原始奖励计算优势并更新模型。
