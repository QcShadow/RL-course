# RL course

这是强化学习课程项目的公开交付仓库。项目在同一套 PCPO OCR 任务、训练提示池和评测协议上，比较 5 个相互独立的贝叶斯优化实验方向。每个方向都可以单独交给一位队友和一个 agent，不需要先运行其它方向。

## 从哪里开始

先打开 [实验目录说明](ideas/README.md)，选择一个方法。进入对应目录后，先读 `README.md`，再读 `README_队友先读.md` 和 `docs/` 下的文件。每个目录同时提供一个同名 ZIP，适合直接发给队友。

每个实验包都包含：

- 固定输入特征或训练状态输入的说明。
- BO 模型、Matérn-5/2 核、UCB 采集函数和状态保存。
- PCPO 接入接口、部署步骤和 agent 任务单。
- 训练提示池、依赖文件、单元测试和 CPU smoke test。

标准接入流程是：

1. 在包目录安装 `requirements.txt` 中的依赖。
2. 运行单元测试和 `examples/cpu_smoke.py`。
3. 按任务单把接口接入队友的 PCPO 训练脚本。
4. 使用独立运行目录先完成 21 轮单 GPU 试跑。
5. 检查日志和断点恢复后，再运行完整训练预算。

| 实验包 | BO 观测或控制量 | 接入位置 | 当前交付状态 |

## 接入边界

v2 已提供针对现有单 GPU PCPO 驱动的训练入口。其它 4 个包提供可复制的 BO 模块、数据适配器和明确的 hook，但没有假造一个不知道队友变量名的 GPU launcher。队友的 PCPO 脚本需要分别完成任务单中标出的 hook，完成后即可使用文档中的试跑命令启动训练。

方法比较时保持相同模型起点、训练图片总数、随机种子、验证预算和独立测试集。最终结论使用独立测试集 OCR reward，不使用训练过程中 BO 的采集分数替代测试指标。

当前版本的 CPU 测试和 smoke test 已通过；真实 GPU 训练结果由队友接入后回传。
