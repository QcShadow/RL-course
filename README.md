# RL course

强化学习课程项目：在 PCPO 的 OCR 任务中使用贝叶斯优化指导训练提示采样。

## 实验目录

[v2 独立实验包](ideas/基于BO的改进强化学习训练采点v2/) · [队友先读](ideas/基于BO的改进强化学习训练采点v2/README_队友先读.md) · [下载 v2 ZIP](ideas/基于BO的改进强化学习训练采点v2.zip)

v2 包提供固定提示特征与 Matérn-5/2 核、GP、UCB/logEI 选点、奖励归组、断点恢复，以及针对现有单 GPU PCPO 驱动的接入代码。

每轮选择 8 条提示，每条生成 8 张图，前 20 轮随机预热，随后按最近 50 轮观测选点。整次训练不重复提示文本。v2 优先选择预测组内 reward 方差较大的提示。PCPO 始终使用原始奖励计算优势并更新模型。

## 独立候选方法

下面四个目录是独立实验包。它们不修改 v2 的代码或状态，队友可以分别复制一个目录接入同一份 PCPO 基线。

| 方法 | BO 观测 | 改动位置 |
|---|---|---|
| [有效学习信号选点](ideas/BO有效学习信号选点/) | 每条提示的有效 PCPO 优势幅度 | 选下一轮提示 |
| [梯度对齐选点](ideas/BO梯度对齐选点/) | 提示组梯度与参考梯度的余弦相似度 | 选下一轮提示 |
| [在线 PCPO 参数调节](ideas/BO在线PCPO参数调节/) | 验证集 reward 增量与实际 KL | 选择 KL 系数和学习率 |
| [图片预算分配](ideas/BO图片预算分配/) | 每条提示的组内 reward 波动 | 分配每条提示的图片数 |

四个包都提供 CPU 测试和合成数据 smoke test。它们只验证接口和 BO 控制逻辑，真实 GPU 训练需要队友在 PCPO 服务器上完成。方法对比时保持相同模型起点、训练图片总数、seed 和独立测试集。
