# 来源与交付范围

本包包含运行 BO 所需的独立组件、针对队友复现驱动的适配，以及交付文档。

## 方法与代码

- 特征：1530 维确定性提示表示，定义见 `pcpo_bo/features.py` 和 `pcpo_bo/assets/feature_schema.json`。
- 核：共享长度尺度 Matérn-5/2，构造参数和先验见 `pcpo_bo/kernel.py`。
- GP：使用 BoTorch 的 SingleTaskGP、高斯似然和 Y 标准化。长度尺度与噪声从新训练数据拟合，特征保持固定。
- 采集函数：UCB 或 BoTorch 0.18.1 的稳定 logEI。v2 最大化组内 reward 方差。
- PCPO 适配：以队友提供的普通复现 `train_sd3_PCPO_paper.py`、`paper_rank_start.py`、`paper_launch.py`、`run_paper_task.sh` 为基础；差异文件随包。
- 提示池：来自同一资料包作者 Flow 分支快照的 `dataset/ocr/train.txt`，原始行序保留。

## 运行数据

运行时需要 `pcpo_bo/` 模块与训练 Dataset。`reference_data/` 保存历史整轮均值作背景资料，不会被 selector 作为逐提示标签读取。正式观测从新训练的预热阶段收集。

PCPO 的基础模型、LoRA 检查点、OCR 模型和 HDF5 embedding 使用队友原服务器上的文件。新入口继续依赖原工程的 runtime、config 和 FlowGRPO 模块。具体路径由队友原启动脚本配置。

## 使用范围

当前完整驱动适配限定为单 GPU、OCR-only、每轮8提示×8图。底层 selector 可以嵌入别的训练器，但 reward 输入仍是逐提示的图像奖励组。多 GPU 广播、联合批量采集、动态重新设计核不在本版中。

本包包含 v2 的 CPU 测试记录；v2 尚未完成真实 GPU 训练。合成奖励仅用于验证代码，不计入科研实验。
