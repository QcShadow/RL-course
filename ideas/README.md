# 实验目录

当前提供 5 个相互独立的实验包。每个包都可以单独交给一位队友和一个 agent，不能把一个包当成另一个包的前置步骤：

- [基于BO的改进强化学习训练采点v2](基于BO的改进强化学习训练采点v2/)：预测提示组内 OCR reward 方差，默认直接运行这一组。
- [BO有效学习信号选点](BO有效学习信号选点/)：预测裁剪后优势的幅度，验证它是否比直接方差更贴近 PCPO 学习信号。
- [BO梯度对齐选点](BO梯度对齐选点/)：预测提示组梯度与固定参考梯度的方向一致性。
- [BO在线PCPO参数调节](BO在线PCPO参数调节/)：调节 PCPO 的学习率和 KL 系数，验证训练控制层的 BO。
- [BO图片预算分配](BO图片预算分配/)：在每轮 64 张图总预算不变时，调节不同提示的图片数量。

对应压缩包：

- [有效学习信号选点 ZIP](BO有效学习信号选点.zip)
- [梯度对齐选点 ZIP](BO梯度对齐选点.zip)
- [在线 PCPO 参数调节 ZIP](BO在线PCPO参数调节.zip)
- [图片预算分配 ZIP](BO图片预算分配.zip)

v2 包默认直接运行，不要求队友先运行其它版本。其它四个包是独立研究方向。每个包都有自己的接口、状态文件、部署文档和运行目录，不能混用。

后续新增方法时，在 `ideas/` 下建立新的独立文件夹，并为它提供自己的 README、运行目录和 ZIP。不同方法不能共用 BO 状态文件。
