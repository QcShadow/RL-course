# 特征与接入对齐

## 固定特征是什么

提示候选使用 v2 冻结的 1530 维确定性文本表示：16 个结构统计量、38 个目标字符计数、1444 个相邻字符组合计数、32 个引号外语境线索。它只由提示文本决定，不读取 reward 或最终测试集。

特征实现是 `pcpo_bo/features.py`，结构定义是 `pcpo_bo/assets/feature_schema.json`。目标文字取第一对 ASCII 双引号，字符统计去普通空格并转小写；引号外语境单独编码。候选池行号必须和训练 Dataset、HDF5 顺序一致。

这套特征是之前离线确定并冻结的表示方案。BO 只学习“特征到梯度对齐观测”的关系，不在训练中重新设计特征。

## 队友需要复用什么

```python
from pcpo_bo.features import encode_rows
features = encode_rows([{"prompt": text} for text in train_dataset.prompts])
selector = GradientAlignmentSelector(features, seed=42)
```

要求 `features.shape == (候选数量, 1530)` 且为 `torch.float64`。不要对候选池重新排序、去重或用 token ID 代替行号。

## PCPO 接入改写

1. 在 DataLoader 迭代前调用 `next_batch()`。
2. 生图和 OCR reward 仍走原 PCPO 流程。
3. 对每个选中提示组，使用原 PCPO loss 对 LoRA 参数求梯度，得到一个梯度向量；在固定训练参考集上得到 `reference_gradient`。
4. 将 8 个组梯度和参考梯度传给 `observe(ids, group_gradients, reference_gradient)`。

参考集不能使用最终测试集。建议只取 LoRA 梯度并做固定随机投影，所有 seed 使用同一投影矩阵。PCPO 的 reward、优势、截断目标和 KL 项不改；本包只决定下一轮提示。
