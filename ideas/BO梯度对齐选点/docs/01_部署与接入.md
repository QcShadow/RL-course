# 部署与接入

## 交付边界

本包包含独立的 1530 维提示特征、梯度展平和随机投影、余弦对齐、GP 选点、状态保存和 CPU 测试。梯度必须由队友 PCPO 训练脚本产生，因此完整 GPU 入口保留三个明确 hook。

## 1. 安装和 CPU 验证

```bash
python -m pip install -r requirements.txt
PYTHONPATH=. python -B -m unittest discover -s tests -v
PYTHONPATH=. python -B examples/cpu_smoke.py
```

## 2. 初始化和选点

```python
from integration.features import encode_rows
from bo_align import GradientAlignmentSelector

features = encode_rows([{"prompt": text} for text in train_dataset.prompts])
selector = GradientAlignmentSelector(features, seed=42)
selected = selector.next_batch()
train_sampler.set_indices(selected)
```

## 3. 三个 PCPO hook

在同一轮 reward 和 PCPO loss 可用时完成：

```python
from bo_align.integration import flatten_parameter_grads, group_gradient_matrix

# hook 1: 对每个提示组构造原 PCPO loss，并调用 torch.autograd.grad
# hook 2: 对固定训练参考集构造同一个 PCPO loss，得到 reference_gradient
# hook 3: 只保留 LoRA 参数梯度，必要时用固定 projection 压到 64/128 维
record = selector.observe(selected, group_gradients, reference_gradient)
```

这三处无法在独立包内自动完成，因为 loss、LoRA 参数和参考集对象属于队友训练脚本。参考集不能使用最终测试集。PCPO 的原始 reward、优势、截断和 KL 项不改。

## 4. 试跑和验收

先跑 21 轮并记录每组梯度范数、参考梯度范数和 alignment 分布。若出现全为 0、NaN 或显存超限，先停止完整训练。通过后另开 250 轮目录。

```bash
export PCPO_TARGET_EPOCHS=21
export PCPO_RUN_ROOT=/path/to/runs/gradient_alignment_seed42
bash /path/to/pcpo/jobs/run_task.sh ocr "$GPU_ID" 1
```

验收必须包含：梯度投影维度、参考集提示列表、每轮 8 个 alignment、额外反向耗时和独立测试结果。
