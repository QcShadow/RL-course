# 特征与接入对齐

## 固定特征是什么

提示选点复用 v2 的 1530 维确定性文本特征：16 个结构统计量、38 个目标字符计数、1444 个相邻字符组合计数、32 个引号外语境线索。特征由提示文本决定，不读取 reward，也不在训练中重新学习。

使用 `pcpo_bo/features.py` 和 `pcpo_bo/assets/feature_schema.json` 编码完整训练池。候选池行号必须保持和训练 Dataset、HDF5 一致，矩阵类型为 `torch.float64`，不能使用 tokenizer token ID。

## PCPO 接入改写

1. 先用完整候选池特征创建 `BudgetAllocator`。
2. 每轮调用 `next_batch()`，得到 8 个数据集行号和对应 `image_counts`。
3. 修改 DataLoader，使每个行号按自己的 `image_counts` 重复；总数仍必须为 64。
4. OCR reward 收集后按变长分组调用 `observe(prompt_indices, image_rewards)`。
5. PCPO 优势计算从固定每组 8 张改为按 `image_counts` 分组，并重新检查 batch size、梯度累积和统计器逻辑。

这个包改变的是样本分配和分组大小，不能直接套用 v2 的固定 8×8 `observe_flat` 接口。PCPO 的原始 reward 方向和损失公式保持不变。
