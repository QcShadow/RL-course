# 特征与接入对齐

## 固定特征是什么

本包使用 v2 已冻结的 1530 维提示文本表示。它是确定性的文本编码，不是训练过程中重新学习的 embedding，也不是 BO 每轮自动设计的特征。

1530 维由四部分组成：

| 维度 | 内容 |
|---:|---|
| 16 | 目标长度、词数、数字和标点比例、大小写、引号结构等统计量 |
| 38 | 引号内目标文字的字符计数 |
| 1444 | 38×38 的相邻字符组合计数 |
| 32 | 引号外语境中的字体、载体、光照、模糊、遮挡等词面线索 |

目标文字按评分器约定取第一对 ASCII 双引号之间的内容；字符统计使用去普通空格并转小写的版本。引号外的文字单独提取，避免把要绘制的文字当成场景描述。

特征只读取提示文本，不读取 reward、图片、测试集或模型参数。候选池第 `i` 行的特征必须对应训练 Dataset 和 HDF5 的第 `i` 行，不能排序、去重或重新编号。

## 队友需要复用什么

从 v2 包复制 `pcpo_bo/features.py` 和 `pcpo_bo/assets/feature_schema.json`，然后一次性编码整个训练池：

```python
from pcpo_bo.features import encode_rows
features = encode_rows([{"prompt": text} for text in train_dataset.prompts])
selector = EffectiveSignalSelector(features, seed=42)
```

矩阵形状应为 `(候选数量, 1530)`，类型为 `torch.float64`。不要改成 tokenizer token ID，也不要只编码当前 batch。

## PCPO 接入改写

`next_batch()` 放在 DataLoader 创建迭代器前；`observe(ids, image_rewards)` 放在 64 张图的 OCR reward 已按提示归成 8×8 后、下一轮选点前。PCPO 仍使用原始 reward 计算优势和 loss，本包只改变下一轮的提示索引。

有效信号标签是裁剪后绝对优势的均值。正式实验要同时记录原始 reward、有效信号、选中索引和 BO 状态，并使用新的运行目录。
