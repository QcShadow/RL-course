# 部署与接入

## 交付边界

这个包已经包含提示特征副本、训练提示池、有效信号计算、乱序 reward 归组、GP 选点、状态保存和 CPU 测试。它可以独立安装和验证。

完整 GPU 训练仍需要队友把 `next_batch()` 的结果交给自己 PCPO 脚本的 sampler。这个 hook 依赖队友脚本中的 Dataset 变量，包内没有假造一个通用 launcher。

## 1. 安装和 CPU 验证

从本目录执行：

```bash
python -m pip install -r requirements.txt
PYTHONPATH=. python -B -m unittest discover -s tests -v
PYTHONPATH=. python -B examples/cpu_smoke.py
```

## 2. 接入 PCPO

```python
from integration.features import encode_rows
from bo_signal import EffectiveSignalSelector
from bo_signal.integration import observe_flat, prompt_rows

rows = prompt_rows(train_dataset.prompts)
features = encode_rows(rows)
selector = EffectiveSignalSelector(features, seed=42)

# 每轮 DataLoader 开始前
selected = selector.next_batch()
train_sampler.set_indices(selected)

# 64 张图的 OCR reward 和原始 Dataset 行号收集完成后
record = observe_flat(selector, gathered_dataset_indices, gathered_ocr_rewards)
```

`gathered_dataset_indices` 必须来自 Dataset 的原始 `indices` 字段，不能用 tokenizer ID。PCPO 仍使用原始 reward 计算优势和 loss。

## 3. 队友必须改的 hook

| 位置 | 要改什么 | 包内状态 |
|---|---|---|
| DataLoader 迭代前 | `train_sampler.set_indices(selector.next_batch())` | 已给调用方式，变量名需按脚本替换 |
| reward 收集后 | 调用 `observe_flat` 并保存 record | 已实现 |
| epoch 结束 | 保存 `selector.save_state()`，与 PCPO checkpoint 同 epoch | 已实现接口，需放入脚本 |

## 4. 试跑和正式训练

先使用独立运行目录完成 21 轮试跑，确认第 21 轮已经从随机预热进入 GP 选点；再另开目录跑 250 轮。环境变量和启动脚本沿用队友的单 GPU PCPO 资源配置，只替换 Python 入口和 `PYTHONPATH`。

```bash
export PCPO_TARGET_EPOCHS=21
export PCPO_RUN_ROOT=/path/to/runs/effective_signal_seed42
bash /path/to/pcpo/jobs/run_task.sh ocr "$GPU_ID" 1
```

## 5. 验收

检查 `events.jsonl` 中每轮有 8 个 prompt index、8 个 signal、64 个原始 OCR reward，且 `selection_method` 在预热后变为 `ucb`。最终报告同时交回独立测试结果和训练池覆盖数。
